# AMR 靶球车安卓协作开发文档

## 1. 文档目的

本文档用于向安卓工程师说明 AMR 靶球车项目背景、业务流程、模块边界和 APP 侧需要实现的功能。当前方案中，视觉识别与坐标计算由 C++ 动态库提供，安卓 APP 负责 UI 交互、RTSP 视频展示、用户输入、AMR 控制器接口调用、任务状态展示与上位机任务联动。

资料来源：

- `readme.md`：项目背景、顶盖解析、坐标转换、靶球任务流程。
- `references/NEST X使用文档.docx`：NEST 控制器 API、建图、导航、地图、机器人状态、网络配置等接口。
- `references/靶球车体ui设计.docx`：APP 页面与交互功能草案。
- `references/项目内容 (1).docx`：系统架构、硬件配置、APP 交付功能描述。

## 2. 项目背景

系统由基座、顶盖、AMR 底盘、RGB 相机、NEST-A 导航控制器和安卓 APP 组成。

基座在 AMR 地图中表现为环形或圆形区域，由 AMR 使用激光 SLAM 建图。顶盖为空心半球结构，每次任务前会重新倒扣在基座上。顶盖相对基座的位置每次可能变化，主要变化是绕圆心旋转。因此，每次任务开始前都需要重新标定顶盖在 AMR 地图中的姿态，并将顶盖图纸中的喇叭口坐标映射到 AMR 地图坐标系。

顶盖上存在两类关键视觉目标：

- 入口通孔：位于顶盖边缘一圈，用于确定顶盖相对基座的旋转方向和入口基准。
- 中心喇叭口：用于辅助确定顶盖中心基准。

## 3. 系统分工

### 3.1 C++ 动态库负责

- 接收或处理 RTSP 视频流中的图像帧。
- 对入口通孔、中心喇叭口进行圆形识别。
- 输出识别结果，包括圆心像素坐标、半径、置信度、序号候选等。
- 输出处理后的视频帧，用于 APP 叠加或展示识别圈注效果。
- 根据 APP 提供的用户确认结果、输入高度、AMR 当前位姿、相机安装参数、顶盖型号或图纸数据，计算入口通孔和中心喇叭口在 AMR 地图中的坐标。
- 根据入口基准、中心基准和顶盖图纸数据，计算全部喇叭口在 AMR 地图中的坐标，并一次性返回给 APP。

### 3.2 安卓 APP 负责

- 提供项目主流程 UI。
- 获取并展示 AMR 的 RTSP 视频流。
- 展示 C++ 动态库处理后的视频流或识别圈注结果。
- 提供顶盖型号选择、识别开始、识别结果选择、入口通孔序号输入、高度输入、确认等交互。
- 暂存用户确认的入口通孔识别结果、入口通孔序号、高度、中心喇叭口识别结果等标定数据。
- 调用 C++ 动态库完成坐标计算。
- 调用 AMR/NEST API 完成建图、导航、地图加载、手动遥控、任务取消、状态确认等功能。
- 保存 C++ 动态库返回的全部喇叭口坐标表。
- 作为 Modbus TCP 服务器监听上位机写入的目标点位序号，将序号转换为对应 AMR 坐标并发送给 AMR 执行。
- 通过 Modbus TCP 只读寄存器向上位机提供 AMR 状态，例如空闲、执行中、成功、失败、取消。
- 展示地图、AMR 实时位姿、任务状态和网络配置。

### 3.3 AMR/NEST 控制器负责

- 激光 SLAM 建图与定位。
- AMR 地图维护、导航程序启动、地图切换。
- 机器人实时位姿、速度、状态上报。
- 速度控制、前往目标点、取消任务、状态确认、举升高度、重定位等控制能力。

### 3.4 上位机负责

- 在靶球任务阶段作为 Modbus TCP 客户端，向 APP 任务控制寄存器写入目标点位序号。
- 读取 APP 提供的只读状态寄存器，获取 AMR 当前状态，例如空闲、执行中、成功、失败、取消。

## 4. 主业务流程

### 4.1 初始化与配置

1. APP 连接 AMR 控制器网络。
2. 用户在 APP 中选择顶盖型号或堆型编号。
3. APP 加载对应顶盖图纸解析数据。当前资料中提到格式可以是 XML 或其他格式，具体字段仍待算法定稿。
4. APP 启动或确认导航程序，并显示当前 AMR 地图和底盘实时位姿。

### 4.2 入口通孔识别与确认

1. 用户通过 APP 遥控或导航 AMR 到基座入口处。
2. AMR 上方向 RGB 相机通过 RTSP 输出视频流。
3. C++ 动态库后续直接接入 RTSP，使用 FFmpeg 解码；APP 负责配置、控制、显示和业务交互。
4. C++ 动态库识别画面中的圆形通孔，并返回候选结果和处理后画面。
5. APP 在视频画面上显示识别圈注结果。
6. 用户选择入口通孔识别结果，输入入口通孔序号和高度。
7. APP 暂存以下数据：
   - 顶盖型号。
   - 入口通孔序号。
   - 用户选择的入口通孔识别结果。
   - 高度值。
   - 当前 AMR 位姿。
   - 当前地图 ID 或地图名称。
8. APP 将上述数据传给 C++ 动态库，计算入口通孔在 AMR 地图中的坐标。

### 4.3 中心喇叭口识别

1. 用户通过 APP 遥控 AMR 到基座中心喇叭口附近，使相机可看到中心喇叭口。
2. APP 继续展示 RTSP 视频流和识别结果。
3. C++ 动态库识别中心喇叭口。
4. 用户从识别候选中确认中心喇叭口，不需要输入喇叭口序号。
5. APP 暂存中心喇叭口识别结果、当前 AMR 位姿、高度等数据。
6. APP 将入口基准和中心基准数据传给 C++ 动态库。
7. C++ 动态库计算顶盖相对 AMR 地图的旋转偏移，并把全部喇叭口在 AMR 地图中的坐标返回给 APP。

### 4.4 靶球任务执行

1. 标定成功后，APP 进入靶球控制页面。
2. APP 作为 Modbus TCP 服务器，等待上位机写入目标点位序号。
3. APP 根据本地保存的全部喇叭口坐标表，将目标点位序号转换为对应 AMR 地图坐标。
4. APP 将目标坐标转换为 NEST `go_to` 或任务点指令。
5. AMR 执行导航，到达目标靶球位置。
6. APP 展示执行中、成功、失败、取消等状态。
7. APP 将 AMR 状态写入 Modbus TCP 只读状态寄存器，供上位机读取。
8. 当前任务结束后，APP 根据控制器状态调用确认接口，使 AMR 回到可接收下一任务的状态。

## 5. APP 功能清单

### 5.1 地图与导航

- 地图列表获取。
- 启动建图程序。
- 保存地图。
- 启动导航程序。
- 切换地图。
- 获取当前运行地图。
- 获取地图数据和部署数据，并在 APP 中渲染地图。
- 展示 AMR 实时位姿、朝向、速度、定位异常、碰撞状态。
- 支持基于地图目标点的导航。
- 支持取消当前任务。
- 支持任务结束后的状态确认。
- 支持 AMR 重定位。可先做基础入口，后续根据现场需求完善。

### 5.2 地图校准页面

页面建议包含：

- 顶部显示加工管座、堆型编号或顶盖型号。
- 地图校准状态。未成功时显示空或“未校准”。
- 顶盖型号选择。
- 入口通孔识别模块：
  - 开始识别。
  - 视频流展示。
  - 识别圈注展示。
  - 识别候选选择。
  - 通孔序号输入。
  - 高度输入。
  - 确认按钮。
- 中心喇叭口识别模块：
  - 开始识别。
  - 视频流展示。
  - 识别圈注展示。
  - 识别候选选择。
  - 高度输入。
  - 确认按钮。
- 校准结果反馈：
  - 校准成功。
  - 校准失败。
- 恢复原始状态或重新校准。

### 5.3 视频与识别展示

- RTSP 视频流播放。
- 开始、停止识别。
- 显示处理后视频帧。
- 在画面上显示圆形识别框、圆心、编号、置信度。
- 用户点击或选择识别候选。
- 识别失败提示和重试。
- 补光灯当前按常开处理，APP 暂不需要提供补光灯开关。

### 5.4 靶球控制页面

- 当前任务状态展示，例如等待任务、执行任务中、任务结束、任务失败、任务取消。
- 任务取消按钮。
- 当前目标靶球序号展示。
- 目标点 AMR 坐标展示。
- AMR 导航状态展示。

### 5.5 手动控制功能

- APP 需要提供手动控制能力，具体交互形式由安卓工程师决定。
- 线速度输入或滑条。
- 角速度输入或滑条。
- 横向速度控制。底盘为双舵轮全向运动模型，NEST 速度控制接口支持 `linear_y`。
- 急停或速度置零。
- 手动控制发送频率建议 10 Hz 到 20 Hz。

### 5.6 任务状态

- 展示 AMR FSM 状态：`idle`、`moving`、`succeeded`、`failed`、`canceled` 等。
- 展示定位异常、导航碰撞、当前速度、当前位姿。
- 展示标定状态：未开始、识别中、待用户确认、计算中、成功、失败。
- 展示上位机任务状态：未连接、等待序号、已收到序号、已下发 AMR、执行完成。

### 5.7 配置与网络

- AMR 控制器 IP 配置。
- RTSP 地址配置。
- C++ 动态库算法参数配置入口，建议仅技术人员可见。
- WiFi 扫描、连接、当前 WiFi 展示。
- 网络接口列表与 IP 地址展示。
- 可选：热点配置、历史 WiFi 管理、静态 IP 配置。

## 6. 安卓与 C++ 动态库接口草案

以下为建议接口形态，最终以 JNI 封装方式为准。

### 6.1 数据结构

```json
{
  "CircleDetection": {
    "id": "候选ID，由算法生成",
    "center_x": "圆心像素x",
    "center_y": "圆心像素y",
    "radius": "半径，像素",
    "confidence": "置信度",
    "type": "entrance_hole | center_target | horn"
  }
}
```

```json
{
  "AmrPose": {
    "x": "地图坐标x，单位m",
    "y": "地图坐标y，单位m",
    "yaw": "朝向，单位rad"
  }
}
```

```json
{
  "CalibrationInput": {
    "top_cover_model": "顶盖型号",
    "map_id": "地图ID",
    "height_mm": "相机到识别目标的高度，单位mm",
    "entrance_hole_no": "入口通孔序号",
    "entrance_detection": "用户选择的入口通孔识别结果",
    "entrance_amr_pose": "入口识别时AMR位姿",
    "center_detection": "用户确认的中心喇叭口识别结果",
    "center_amr_pose": "中心识别时AMR位姿"
  }
}
```

```json
{
  "HornCoordinate": {
    "horn_no": "喇叭口序号",
    "x": "AMR地图坐标x，单位m",
    "y": "AMR地图坐标y，单位m",
    "yaw": "目标朝向，单位rad，可选"
  }
}
```

### 6.2 建议接口

| 接口 | 调用方 | 说明 |
| --- | --- | --- |
| `init(config)` | APP -> C++ | 初始化算法、相机参数、顶盖数据目录等。 |
| `setTopCoverModel(modelId)` | APP -> C++ | 设置顶盖型号。 |
| `startDetect(config)` | APP -> C++ | 开始识别，入口通孔和中心喇叭口通过不同圆检测参数配置区分。 |
| `stopDetect()` | APP -> C++ | 停止识别。 |
| `processFrame(frame)` | APP -> C++ | APP 解码 RTSP 时，逐帧传入算法。 |
| `getDetections()` | APP -> C++ | 获取当前识别候选。 |
| `getProcessedFrame()` | APP -> C++ | 获取圈注后的画面。 |
| `confirmEntrance(input)` | APP -> C++ | 提交入口通孔确认结果，返回入口通孔 AMR 坐标。 |
| `confirmCenter(input)` | APP -> C++ | 提交中心喇叭口确认结果。 |
| `calculateAllHorns(input)` | APP -> C++ | 计算并返回全部喇叭口 AMR 坐标，APP 后续按序号自行查询。 |
| `release()` | APP -> C++ | 释放算法资源。 |

## 8. APP 与上位机 Modbus TCP 对接

APP 端作为 Modbus TCP 服务器，上位机作为 Modbus TCP 客户端。

### 8.1 任务控制寄存器

- 类型：可写寄存器。
- 写入方：上位机。
- 读取或处理方：APP。
- 用途：上位机写入目标点位序号，APP 收到后从本地保存的全部喇叭口坐标表中查找对应 AMR 坐标，并下发给 AMR 执行。

### 8.2 AMR 状态寄存器

- 类型：只读寄存器。
- 写入方：APP。
- 读取方：上位机。
- 用途：向上位机反馈 AMR 当前任务状态。
- 建议状态枚举：
  - `0`：空闲。
  - `1`：执行中。
  - `2`：成功。
  - `3`：失败。
  - `4`：取消。

具体寄存器地址、数据类型、字节序和状态枚举值需要与上位机联调时最终确认。

## 10. 边界处理

- RTSP 断流：APP 提示断流并允许重连。
- AMR WebSocket 断开：APP 显示离线状态并停止发送控制指令。
- 识别不到圆形：APP 显示未识别到目标，允许重试或调整位置。
- 多个候选目标：APP 必须让用户确认，不自动选择最终通孔序号。
- 高度未输入：不允许提交坐标计算。
- AMR 位姿无效或定位异常：不允许确认标定点。
- AMR 处于 `moving` 时：不允许直接下发 `go_to`，除非先取消当前任务并确认状态。
- AMR 任务结束后：需要根据状态调用 `confirmStatus`。
- 顶盖型号未选择：不允许开始最终坐标解算。
- 上位机下发未知靶球序号：APP 返回错误或显示无对应坐标。
- 坐标计算失败：APP 显示失败原因并保留用户输入，便于重新计算。

## 11. 待确认事项

以下内容不影响安卓先做页面和流程骨架，但需要在联调前明确：

- 顶盖图纸解析数据格式：XML、JSON、CSV 或其他格式。
- 顶盖型号与图纸文件的管理方式：APP 内置、服务器下发、用户导入或动态库目录读取。
- 相机内参、畸变参数、相机相对车体安装位姿的配置与版本管理。
- 高度的定义：相机到通孔平面距离、地面到目标高度，还是其他机械基准。
