# amr项目背景
## 环境
环境分为两部分，基座（俯视看是环形/圆形，在地面上amr会用激光扫出来即amr地图）与顶盖（空心半球会像碗一样倒扣在基座上），顶盖上有安装在同一高度的喇叭口，喇叭口口朝下，在顶盖边缘分布有一圈通孔。
## 任务流程
每次任务之前顶盖都会重新倒扣在基座上，所以喇叭口相对于基座地图每次都会变化（主要是绕圆心的旋转），这时候就需要将喇叭口的坐标映射到基座地图（amr地图）上，这样才能进行导航。
### 顶盖解析
将顶盖2D图纸中所需要的数据导入，现在可以是xml或者其他形式，因为现在确定坐标的算法未确定，所以要导入的具体数据未定。
### 坐标转换
amr会先到基座入口处，基座入口上方可以看到顶盖的部分通孔，车体上方有安装向上看的RGB摄像头，amr会将RGB摄像头的视频流通过RTSP协议传到本应用程序上，本程序需对视频做识别（圆形识别），识别出画面中的入口通孔，并且圈出来显示到ui上，工人会在本应用程序上选择入口通孔，并且输入通孔序号，这时我们可以通过RGB摄像头识别出来的像素坐标，摄像头相对于车体的安装位置，摄像头距离通孔的高度，车体现在在地图的位置，计算出通孔在amr地图上的坐标，然后工人将amr开到基座圆心，令摄像头可以拍到中心喇叭口，按照上面算法，得到中心喇叭口在amr地图上的坐标，根据这两个坐标与顶盖图纸解析出的数据，计算出所有喇叭口在amr地图上的坐标。
### 靶球任务
在确定坐标之后，就可以开始靶球任务了，会有一个上位机将任务中的靶球序号依次发给本应用程序，本程序会将靶球序号换成目标靶球在amr地图上的坐标并且发送到点指令给amr小车，令小车到达目标靶球
